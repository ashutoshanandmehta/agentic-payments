Research prototype · IIT Kanpur

Trusted delegated payments for AI agents.

A control layer above UPI and card rails: the agent proposes a payment, a deterministic gate decides, and signed receipts preserve the evidence.

This is a simulation, not a live payment service. The work asks whether an agent was permitted to pay—and whether that permission can be proven afterwards.
